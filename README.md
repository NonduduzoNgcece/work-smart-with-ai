# AI Productivity Assistant - Work Smart With AI

A unified productivity dashboard that brings together multiple AI-powered tools to help you work smarter, not harder.

**Live Demo:** https://work-smart-with-ai.lovable.app

## Features

### 1. AI Email Generator
Generates professional emails instantly in 3 tones: Formal, Friendly, and Persuasive.

### 2. Meeting Notes Summarizer
Takes long meeting transcripts and summarizes them into key points and action items.

### 3. Task Planning Assistant
Helps prioritize tasks and plan your daily workflow using AI.

## Tech Stack
- Lovable
- React + TypeScript
- Tailwind CSS
- Supabase
- OpenAI / Lovable AI Gateway
